# Dynamic Service

A React + Vite event-services website inspired by the page structure of Eva Wellness Spa, redesigned for **Dynamic Service**: decoration, ceremony animation, sound/lighting and equipment rental.

## Pages
- `/` Home
- `/services` Services
- `/gallery` Gallery
- `/about` About Us
- `/contact` Contact
- `/book` Booking

## Run locally
1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the Vite URL shown in the terminal, usually `http://localhost:5173`.

## Production Node.js server
Build first:

```bash
npm run build
```

Then:

```bash
npm run server
```

Open `http://localhost:5000`.

## Images and logo
The project includes original SVG artwork in `public/images/` so the site works without depending on external image hosting.

## Important
The visual hierarchy is inspired by the referenced wellness site, but the branding, copy, artwork and business content are original for Dynamic Service. Replace the placeholder phone/email/location with your real business information.
